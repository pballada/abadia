# 0.3.0 — one-click setup, original Amstrad graphics, automatic updates

- **Download Game Data.** On first launch, one click fetches the disk image, both graphics packs and the music and effects (about 6 MB). They come from the pinned Abbey commit on GitHub, and each file is checked against a known SHA-256 before the game starts. **Use a Folder…** still imports files you already have.
- **Original Amstrad graphics.** View → Original Amstrad Graphics (⌘G) switches between the 256-colour remake and the four-colour 1987 Amstrad CPC graphics, even mid-game. The engine always had this ability; the CPC pack was loaded but never shown.
- **Sharper scaling.** At window sizes that aren't a whole multiple of 640 × 400, every game pixel is now drawn the same size (sharp bilinear), instead of alternating narrow and wide columns. View → Pixel-Perfect Scaling limits the image to whole multiples.
- **Automatic updates.** The app checks GitHub once a day, verifies the Developer ID signature and team of a new release, replaces itself and relaunches. Abadía → Check for Updates… checks now; the same menu turns automatic checks off. Updating from 0.2.x to 0.3.0 is manual, one time only.
- **Audio.** Music and effects are loaded at startup, so the first effect plays without delay. These audio fixes were prepared as 0.2.2 and ship here:
  - Title, prologue, gameplay and ending each start the right track (`inicio`, `fondo`, `final`) without restarting it on every tick.
  - Mute and pause keep the music's position. Switching music no longer cuts sound effects.
- Holding Option at launch now returns to the setup screen, to download or choose the data again. Saves are kept.

Game data is still not bundled. It is downloaded only when you click the button.
