# 0.2.2 — audio playback fixes

Prepared locally; the published notarized download remains v0.2.1 until a new
0.2.2 archive is signed, notarized, and uploaded.

- Title and prologue use `inicio.wav`, gameplay uses `fondo.wav`, and the ending
  uses `final.wav`. New games, loading, and returning to the title select the
  appropriate music without restarting it on every game tick.
- Mute and pause preserve the music position. Unmuting while paused stays silent;
  resuming while muted stays silent. Repeated pause requests preserve active effects.
- Switching or stopping music no longer stops sound effects. Muting discards
  one-shot effects so they do not replay later.
- Quit and reopen while holding Option to reimport a complete data folder,
  including any WAV files missing from an earlier import. Saves are retained.
- The README starts with the ordinary download-and-open installation. Build and
  signing commands are in the developer section; checksum verification is optional.

The app still requires separately supplied game data. No music or effects are
bundled in the download.

Validation: native and Intel builds, device-independent audio regressions,
real-data smoke tests on both architectures, and AddressSanitizer /
UndefinedBehaviorSanitizer smoke tests. These checks cover track selection and
playback control; they do not certify audible output on hardware.
