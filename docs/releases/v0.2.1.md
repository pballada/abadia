# v0.2.1 — Original pixels and pathfinding crash fix

Native universal macOS build for Apple Silicon and Intel. Requires macOS 13 or later.

## Changes

- Fix an abort in monk path planning when leaving a slope at a screen boundary. Reconstruction now finishes the valid movement prefix and requests a fresh route.
- Restore original pixels throughout the renderer; remove edge smoothing and its menu options.
- Remove the decorative game frame and keyboard legend.
- Remove the icon's outer rounded-square tile, retaining a transparent Gothic doorway and crimson book.

## Verification

The new slope-exit regression reproduces the exact assertion from the reported 0.2.0 crash in the unfixed code. It passes after the fix. The gameplay and seven-slot save/load smoke checks pass, as does the regression under AddressSanitizer/UndefinedBehaviorSanitizer and Intel/Rosetta. This does not claim a full seven-day playthrough.

Save compatibility is unchanged from 0.2.0: earlier 0.1 saves require the earlier app to load. Game data is imported separately and is not included.
